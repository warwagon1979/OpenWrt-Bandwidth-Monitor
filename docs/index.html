OpenWrt Bandwidth Dashboard

A lightweight dashboard for bandwidth monitoring, DNS history, alerts, backups, WireGuard, and Smart Home usage on OpenWrt.

Per-device usageDNS historyEmail alertsSmart HomeBackups

Features

Bandwidth

Track per-device usage, usage history, live bandwidth, groups, and dashboard cards.

DNS Monitoring

Monitor domains, optionally capture external plain DNS, retain history on storage, and search across saved days.

Alerts

Receive email alerts for domain activity, thresholds, Smart Home events, and minimum usage by time.

Smart Home

Water, electricity, temperature, and humidity monitoring with comparisons and history.

Backup & Restore

Automatic backups, full restores, flash-drive browsing, and downloadable saved backups.

Router Monitoring

CPU/process information, WireGuard peer statistics, and device management.

DNS history search

Persistent DNS logging can store recent DNS records on the storage selected during setup instead of RAM. Searches can span all retained history, highlight matching dates on a calendar, filter to a specific day, or show all results in a continuously scrolling list.

Minimum Usage by Time

Set a device, Upload or Download, MB or GB, an amount, and a deadline. If the device has not reached that amount by the selected time, the dashboard sends an email alert.
